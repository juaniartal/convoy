Convoy is a self-hosted GitHub Actions board for your whole organization — think ArgoCD, but for CI pipelines. It splits what's happening into two views: production deploys, and everything else.

View on GitHub Quick install ↓

Watching a release roll out across dozens of repos usually means opening the Actions tab of every repo by hand. Convoy installs a GitHub App on your org once, listens for webhooks — not polling — and shows every workflow run live, split into Deploys (triggered by a release tag) and Pipelines (everything else).

Install

Self-hosted only — your CI data never leaves your own infrastructure.

# see the README for GitHub App setup first
helm install convoy ./helm/convoy \
  --set-file github.privateKey=./private-key.pem \
  --set github.appId=<APP_ID> \
  --set github.webhookSecret=<WEBHOOK_SECRET> \
  --set ingress.host=convoy.your-internal-domain.com
# see the README for GitHub App setup first
docker run -p 3000:3000 \
  -e APP_ID=... \
  -e WEBHOOK_SECRET=... \
  -e PRIVATE_KEY_PATH=/app/private-key.pem \
  -v $(pwd)/private-key.pem:/app/private-key.pem:ro \
  ghcr.io/juaniartal/convoy:latest

Just want to see it first? npm run demo runs Convoy with fake data — no GitHub App needed.

How it's built

Every decision here traded convenience for something a serious infra team would actually trust.

Delivery

Webhooks, not polling

A GitHub App receives workflow_run/workflow_job events directly. Polling only runs as a slow safety net for missed deliveries — it scales to hundreds of repos without hammering the API.

Trust

Minimal permissions

The GitHub App requests actions: read and metadata: read — nothing else. It can't read file contents, can't write anything, can't touch your workflows.

Data

Self-hosted, always

Ships as a Docker image and a Helm chart. There is no Convoy-operated backend — your CI data never leaves your own cluster.

Classify

Deploy vs. pipeline

A run is a deploy if it's triggered by a release or a version-shaped tag. Everything else is a pipeline. Per-repo overrides handle the exceptions.

Access

Bring your own auth

No "Login with GitHub" to build or trust. Gate the dashboard with your existing SSO/VPN/ingress, or a simple shared API key — same tradeoff Prometheus makes.

License

MIT, free, forever

No paid tier, no telemetry phoning home, no vendor lock-in. Fork it, run it, change it.
